Documentation API - Classe Var

La classe Var permet de stocker différents types de données dans un seul objet grâce à std::variant.

Déclaration 

class Var
{

private:

    using Value = std::variant<
        bool,
        int,
        float,
        double,
        std::string
    >;

};

Constructeurs

Valeurs booléennes 

Var(bool valeur);

Nombres entiers 

Var(short valeur);

Var(int valeur);

Var(long valeur);

Var(long long valeur);

Nombres décimaux 

Var(float valeur);

Var(double valeur);

Var(long double valeur);

Chaînes de caractères 

Var(std::string valeur);

Var(const char* valeur);

Types supportés

Type Description
bool Valeur vraie ou fausse
char Caractère simple
wchar_t Caractère large
short Petit entier
int Entier classique
long long Grand entier
float Nombre décimal
double Nombre décimal précis
std::string Texte
std::wstring Texte large

Afficher une variable

La classe surcharge l'opérateur << pour utiliser directement std::cout. 

Var message = "Bonjour";

std::cout << message;

Fonctionnement interne

Var utilise plusieurs fonctionnalités modernes du C++ :

  • std::variant : stockage de plusieurs types.
  • std::visit : récupération automatique de la valeur.
  • if constexpr : traitement selon le type.
  • std::decay_t : détection du type réel.

Exemple complet 


#include <iostream>
#include "Var.hpp"


int main()
{

    Var nombre = 123;

    Var prix = 9.99;

    Var texte = "Produit";


    std::cout << nombre << std::endl;

    std::cout << prix << std::endl;

    std::cout << texte << std::endl;


    return 0;

}
