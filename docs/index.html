Var

Une bibliothèque C++ moderne permettant de stocker plusieurs types de données dans une seule variable.

Commencer Documentation API

Introduction

Var est une classe C++ basée sur std::variant. Elle permet de manipuler plusieurs types de données avec une syntaxe simple.

Au lieu de créer plusieurs variables différentes, vous pouvez utiliser une seule classe capable de contenir :

  • Des nombres
  • Des caractères
  • Des chaînes de caractères
  • Des valeurs booléennes

Fonctionnalités

Support multi-types

Supporte les types comme int, float, double, string et plus.

Simple à utiliser

Une syntaxe proche des variables classiques du C++.

C++ Moderne

Utilise std::variant, std::visit et les fonctionnalités du C++17.

Exemple rapide 

#include <iostream>
#include "Var.hpp"

int main()
{

    Var nombre = 42;
    Var texte = "Bonjour";
    Var nombreFlottant = 3.14;

    std::cout << nombre << std::endl;
    std::cout << texte << std::endl;
    std::cout << nombreFlottant << std::endl;

}

Pourquoi utiliser Var ?

Var simplifie la gestion des données lorsque le type peut changer. Elle évite de créer plusieurs systèmes de stockage différents.
