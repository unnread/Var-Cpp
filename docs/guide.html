Guide de démarrage

Ce guide explique comment installer et utiliser la bibliothèque Var dans un projet C++.

Installation

Ajoutez simplement le fichier : 

Var.hpp

Puis incluez-le dans votre programme : 

#include "Var.hpp"

Configuration du compilateur

Var utilise les fonctionnalités du C++17. Vous devez donc compiler avec C++17 ou une version supérieure. 

g++ main.cpp -std=c++17 -o programme

Premier programme 

#include <iostream>
#include "Var.hpp"


int main()
{

    Var age = 10;

    Var nom = "Youness";


    std::cout << nom << std::endl;

    std::cout << age << std::endl;


    return 0;

}

Plusieurs types

Une variable Var peut contenir différents types : 


Var a = 100;

Var b = 5.5;

Var c = "Hello";

Var d = true;

Afficher une valeur

L'opérateur << permet d'afficher automatiquement la valeur contenue dans Var. 


std::cout << variable;

Conseils

  • Utilisez C++17 minimum.
  • Gardez Var.hpp dans votre projet.
  • Utilisez Var quand le type de donnée peut changer.
